# SQL Analysis

This folder contains the SQL work for the Nigerian Fintech Transaction Analysis project.

## Purpose
SQL is used to query the transaction data and answer specific business questions about customers, revenue, regions and failed transactions.

## Planned Contents
- Table creation and data import scripts
- Queries for transaction trends (daily, weekly and monthly volumes)
- Queries for customer behaviour (top customers, repeat usage)
- Queries for revenue and regional performance
- Queries for failed transactions and failure rates

## Tools Used
- SQL (SELECT, WHERE, GROUP BY, JOIN, aggregate functions)
