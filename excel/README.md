# Excel Analysis

This folder contains the Microsoft Excel work for the Nigerian Fintech Transaction Analysis project.

## Purpose
Excel is used to clean, explore and summarise the transaction data before deeper analysis in SQL and Tableau.

## Planned Contents
- Data cleaning workbook (removing duplicates, fixing formats, handling missing values)
- Pivot tables summarising transactions by month, region and channel
- Charts showing transaction trends and revenue patterns
- Notes on key findings

## Tools Used
- Microsoft Excel (formulas, pivot tables, charts)
