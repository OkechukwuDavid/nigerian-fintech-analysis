# Project Documentation

This folder contains the supporting documentation for the Nigerian Fintech Transaction Analysis project.

## Purpose
Documentation explains how the project was done, what was found and what decisions were made, so that anyone reading the repository can follow the work.

## Planned Contents
- Data dictionary (what each column in the dataset means)
- Data cleaning log (problems found and how they were fixed)
- Business questions the project answers
- Summary of key findings and insights
- Recommendations based on the analysis

## Tools Used
- Markdown (.md) files for writing documentation
