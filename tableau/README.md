# Tableau Dashboards

This folder contains the Tableau work for the Nigerian Fintech Transaction Analysis project.

## Purpose
Tableau is used to turn the cleaned data and analysis results into interactive dashboards that make trends and patterns easy to understand.

## Planned Contents
- Transaction trends dashboard (volume and value over time)
- Revenue patterns dashboard
- Regional performance dashboard (Lagos, Abuja, Port Harcourt and others)
- Customer behaviour dashboard
- Failed transactions dashboard
- Screenshots of the final dashboards

## Tools Used
- Tableau Public (charts, filters, maps, dashboards)
