# Nigerian Fintech Transaction Analysis

## Project Overview
This project focuses on analysing financial transactions from a fictional Nigerian fintech company to uncover meaningful business insights and transaction patterns.

The analysis will involve data cleaning, querying, exploration and visualization using Excel, SQL and Tableau.

## Project Objectives
- Analyse transaction volumes and values.
- Identify transaction trends and patterns.
- Examine transaction success and failure rates.
- Investigate customer transaction behaviour.
- Compare transaction activities across Nigerian regions.
- Develop actionable business recommendations.

## Tools and Technologies
- Microsoft Excel – Data cleaning and exploration.
- SQL – Data querying and analysis.
- Tableau – Data visualization and dashboard development.
- GitHub – Project documentation and version control.

## Project Structure
The project will contain:
- Dataset
- Excel analysis
- SQL queries
- Tableau dashboards
- Project documentation
